# PocketSmart AI

PocketSmart AI is a FastAPI + Jinja2 Generative AI budget planning application.

## Features

- Home Interior Planner
- Party Budget Planner
- Jewelry Planner
- Gemini AI integration
- Optional jewelry outfit image analysis
- Local fallback recommendation engine
- User registration
- Login
- JWT authentication
- Session cookies
- Recommendation history
- SQLite database
- Responsive frontend
- API endpoints
- Marketplace search links

## Requirements

- Python 3.11+
- VS Code
- Internet connection for installing packages
- Gemini API key for Gemini functionality
